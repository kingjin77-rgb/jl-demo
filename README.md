# 입주예정자협의회 통합 관리 플랫폼 — 데모

법무법인 제이엘이 단지마다 제작하는 입주예정자협의회 전용 플랫폼의 **단지명 없는 범용 데모**입니다.

👉 **https://kingjin77-rgb.github.io/jl-demo/**

PC에서는 홈페이지, 휴대폰에서는 앱처럼 동작합니다.

## 데모 안내

입력하신 내용은 **이 기기 안에만 임시로 남고 어디에도 전송되지 않습니다.**
관리자 화면의 「데모 데이터 처음 상태로 되돌리기」로 언제든 초기화할 수 있습니다.

- 임원 입장 코드 : `1234`
- 표시된 세대수·접수 현황·회비 내역은 설명을 위한 예시입니다.
- 카카오 알림톡은 화면만 재현한 것으로 실제 발송되지 않습니다.

## 기능

**입주민**
- 전자 위임장 — 3단계(세대 확인 → 정보 입력 → 동의·서명), 공동명의 2인 서명
- 입주민 한마디 — 150자 단문 피드, 태그·공감·답글·익명
- 게시판 — 분류·검색·댓글
- 투표·설문 / 임원 선거(위임장 제출 세대만, 1세대 1표)
- 총회 — 참석 의사 등록, 참석·위임 실시간 집계
- 회비 — 우리 집 납부 확인, 동별 납부율
- 계약 분석 — 분양공고문 독소조항과 법무법인 의견
- 법률 상담 신청 / 자료실 / 내 접수 확인 / 명의변경 신고

**임원**
- 접수 내역·미접수 세대·CSV 내려받기
- 회비 미납 명단 CSV
- 지출 승인(영수증 첨부·과반 승인)
- **위임 현황 확인서** A4 발급 — 공문 첨부용
- 총회 소집공고문·의결서·회의록 자동 생성
- 카카오 알림톡 발송(대상·단가·비용 산정)

## 단지 유형

| 유형 | 단체명 | 상황 |
|---|---|---|
| **신축 입주 단지** | ○○아파트 **입주예정자협의회** (입예협) | 입주 전. 사전점검·하자·입주지정기간이 쟁점 |
| **분양전환 단지** | ○○아파트 **분양전환추진위원회** (분추위) | 이미 수년 거주. 전환가격·감정평가가 쟁점 |

`config.js` 의 `type` 을 `newbuild` / `conversion` 으로 지정하면 화면 문구가 맞춰집니다.

> 조합이 아닌 임의단체이므로 **'총회'라는 용어를 쓰지 않습니다.**
> 규약에 정한 명칭(전체회의·정기회의 등)을 `config.meeting` 에 넣습니다.

## 파일 구성

새 단지를 만들 때는 `config.js` 하나만 교체합니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 배포용 — 아래 3개를 하나로 합친 파일 |
| `app.html` | 화면 구조와 디자인 |
| `app.js` | 공통 동작 (단지와 무관) |
| `config.js` | **단지 정보** — 단지명·동·세대수·색상·문구 |
